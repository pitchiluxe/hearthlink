Before you install

  • Connect both PCs to the same LAN, or use a VPN.
  • Install the latest version on both computers.
  • Allow incoming connections only on a trusted Private network.
  • Compare the pairing identities before approving access.

What to expect

The current build supports attended screen sharing, keyboard and mouse control, and switching between displays. The remote PC must approve each session.

File transfer, clipboard sync, unattended access, and remote restart are still being developed. Performance varies; two-PC acceptance testing is ongoing.

The installer is currently unsigned. Windows may show an unknown-publisher notice. Download only from the official release page and compare the published checksum.

A few practical details

Will it work with Windows 11 Home?

Yes. HearthLink uses its own desktop sharing connection and does not require the Windows Pro Remote Desktop host.

Can I connect across the internet?

This build is designed for LAN or VPN connections. It does not include an internet relay or automatic router setup.

How do updates work?

In version 0.2.1 and later, open App updates to check GitHub Releases. Automatic checks can notify you when a newer installer is available. Downloading and installation remain your choice. Existing 0.2.0 installations need the first update-enabled installer installed manually.

The connection won’t open. What should I check?

Keep HearthLink open on the remote PC with incoming sessions enabled. Use its connected Wi-Fi or Ethernet address, check that the trusted home network is Private, and allow HearthLink’s TCP 45831 rule on that network. Do not turn off your firewall.
