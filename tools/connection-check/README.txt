HearthLink connection check

1. Copy/extract this folder on TECHNODESK, the other physical PC.
2. Keep HearthLink open there with Allow incoming sessions checked.
3. Double-click Run-Connection-Check.cmd.
4. Read the report and share its text in the chat.

This is a read-only diagnostic. It changes no network, firewall, service or
Windows remoting settings. It collects no pairing codes or credentials.
The execution-policy flag applies only to this one diagnostic process;
it does not change the computer's execution policy.

The report is saved beside the launcher with the computer's name.
Run it as your normal Windows user. If a section cannot be read, include
that error in the report; do not disable security protections.
